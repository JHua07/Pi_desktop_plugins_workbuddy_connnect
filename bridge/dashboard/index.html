三步接入 PI

仅需配置一次
  1. 1
    登录对应渠道的官方客户端

    国内与国际账号独立，请先安装并登录自己的账号。

  2. 2
    在 PI 设置 → 模型中添加提供商

    选择 OpenAI 兼容 / Chat Completions，填写左侧名称、地址与密钥。

  3. 3
    拉取模型，或填写准确的模型 ID

    从下方目录复制 ID，保存后再按需开始对话。

页面不会自动测试聊天或消耗对话额度。模型目录刷新不会更新 PI 已保存的模型。

03 / LOCAL SERVICE

运行管理

—

Windows 登录时自动启动

仅修改登录自启动，不重启当前服务，不创建重复实例。

停止本地桥接服务

停止后 PI 无法通过此连接发送请求；在源码目录运行 ui 命令可重新启动。

在本地终端恢复连接

在解压后的源码目录打开 PowerShell，任选一种方式启动。自启动已禁用时，请使用前台启动命令。

已安装自动运行任务 · 后台启动
node .\bridge\cli.cjs automation start
前台启动 · 保持终端开启
node .\bridge\cli.cjs start

启动后运行 node .\bridge\cli.cjs ui 重新打开已授权的管理页。
